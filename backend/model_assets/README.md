# TrackNetV3 Model Asset

`tracknetv3_track.pt` contains the inference state dictionary and model parameters
from `qaz812345/TrackNetV3`'s official `TrackNet_best.pt` checkpoint. Optimizer
state was removed to reduce the deployed asset from 130 MB to 43 MB.

- Source: https://github.com/qaz812345/TrackNetV3
- Paper: https://dl.acm.org/doi/10.1145/3595916.3626370
- Upstream checkpoint archive SHA-256: `8de68d34ea2457e368e22947f1309143d60a6a7f9ddccd31cd526d4c4571bcc4`
- Deployed checkpoint SHA-256: `838dc8f6319cc1fc571688aedf5aac00314fc3533c5a1bc33eb5879676e8e801`
